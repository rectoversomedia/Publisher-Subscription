Step 01 — Frontend
Pasang SDK Snippet
Copy-paste 1 baris JavaScript ke article template. SDK otomatis track pageviews dan inject banner container.
// 1 baris di <head> <script src="//sdk.tempo-rb.com/tempo.js"></script>
Effort: 3–5 hari
Step 02 — Events
Kirim Event Data
Fire 7 event types utama: register, login, article_view, paywall_view, offer_click, checkout_start, subscription_success.
TempoRB.track('article_view', { article_id: 'art_123', category: 'Investigation', is_premium: true });
Effort: 2–3 hari
Step 03 — Decision
Revenue Brain decide
Setiap article view → call decision API → dapat action (free/paywall/offer). Banner muncul sesuai decision. Tidak ada logic di frontend.
// Backend / frontend call GET /api/v1/decision ?reader_id=xxx &article_id=yyy → { action: "SHOW_MONTHLY", banner_id: "bn_01" }
Effort: 1–2 hari
Step 04 — Dashboard
Monitor & Optimize
Seluruh funnel dan metric muncul real-time. AI Copilot untuk query natural language. A/B test banner variants.
→ /dashboard/readers // Explorer → /dashboard/banners // Banner manager → /dashboard/analytics // Funnel → /api/copilot/query // AI queries
Effort: 1 hari (onboarding)

Tempo RB SDK — Event Tracking API
JavaScript / TypeScript
// ============================================= // TEMPO REVENUE BRAIN — Event Tracking SDK // ============================================= // Initialize SDK (once, in <head>) const tempoRB = new TempoRB({ apiKey: 'tk_live_tempo_xxx', environment: 'production' // or 'staging' }); // ─── Identity Events ─────────────────────────── // Fire when reader registers tempoRB.track('register', { name: 'Budi Santoso', // optional email: 'budi@example.com', // optional phone: '+62812345678', // optional method: 'google' // 'email' | 'google' | 'apple' | 'phone' }); // Fire when reader logs in tempoRB.track('login', { user_id: 'usr_abc123', email: 'budi@example.com' }); // ─── Engagement Events ───────────────────────── // Fire on every article page load tempoRB.track('article_view', { article_id: 'art_investigasi_2024', category: 'Investigation', topic: 'Politik', is_premium: true, scroll_depth: 72 // 0–100 }); // Fire when reader hits paywall tempoRB.track('paywall_view', { article_id: 'art_investigasi_2024', offer_id: 'off_monthly_v1' }); // ─── Conversion Events ────────────────────────── // Fire when reader clicks offer banner tempoRB.track('subscription_offer_click', { offer_id: 'off_monthly_v1', banner_id: 'bn_promo_01', plan: 'monthly' }); // Fire when checkout page loads tempoRB.track('checkout_start', { plan: 'monthly', price: 64000 }); // Fire when subscription is confirmed tempoRB.track('subscription_success', { plan: 'monthly', price: 64000, revenue: 64000, article_id: 'art_investigasi_2024' // attribution }); // ─── Revenue Brain Decision ───────────────────── // Call this on article load to get what to show const decision = await tempoRB.decide({ article_id: 'art_investigasi_2024', category: 'Investigation' }); // decision.action: 'ALLOW_FREE' | 'SHOW_MONTHLY' | // 'SHOW_ANNUAL' | 'SHOW_SOFT_PAYWALL' | // 'SHOW_HARD_PAYWALL' | 'SHOW_REGISTRATION' if (decision.action === 'SHOW_MONTHLY') { showBanner(decision.banner); }

API Key Security
Service role key hanya di backend/server. SDK menggunakan read-only key dengan rate limiting. Tidak ada credential di client-side bundle.
RLS di Supabase
Row Level Security aktif di semua tabel. Reader hanya bisa read/update data miliknya sendiri. Service role untuk server-side operations saja.
GDPR / UU PDP Compliant
Data reader bersifat pseudonymous. Email/phone di-hash SHA-256 untuk privacy. Reader bisa request data export atau deletion via API.
Rate Limiting
Event API: 1000 req/min per API key. Decision API: 500 req/min. Dashboard: 100 req/min. Limits bisa di-scale per-client.
