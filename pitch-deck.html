08 — Integrasi
Tempo Revenue Brain
Technical Integration

Implementasi dalam
2–3 sprint

Revenue Brain adalah service terpisah. Tim Tempo hanya perlu install SDK snippet dan integrate event API. Tidak perlu refactor sistem yang ada.

1
Pasang SDK Snippet
Copy-paste 1 baris JavaScript ke article template Tempo. Otomatis track semua pageviews dan article views.
2
Kirim Events
Fire events saat reader berinteraksi: register, login, article_view, paywall_view, offer_click, checkout_start, subscription_success.
3
Revenue Brain decide
Setiap article view → call decision API → dapat keputusan: free/paywall/offer. Banner muncul otomatis sesuai decision.
4
Monitor di Dashboard
Seluruh funnel dan metric muncul real-time di dashboard Revenue Brain. Tidak perlu setup BI tool terpisah.
Contoh SDK Usage:
// Page view
TempoRB.track('page_view', { article_id: 'art_123' });

// Registration
TempoRB.track('register', { name: 'Budi Santoso', email: 'budi@...' });

// Subscription success
TempoRB.track('subscription_success', { plan: 'monthly', revenue: 64000 });
